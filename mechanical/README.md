# Mechanical CAD Files

This directory contains the mechanical CAD models, assemblies, and exported manufacturing files for the Wire EDM wire-feed and wire-tension system.

Some designs appear in more than one file format or in more than one subsystem folder. Native SolidWorks files are included where available, while `.STEP`, `.STL`, and `.3mf` files are included for manufacturing, sharing, or 3D printing.

## Folder Layout

- `CAD Assembly Files/` - native SolidWorks assemblies
- `CAD PART Files/` - native SolidWorks parts and some assembly files stored with their related parts
- `CAD STEP Files/` - exported manufacturing and sharing files, organized by subsystem
- `CAD STEP Files/Custom Tools/` - tool and calibration exports
- `CAD STEP Files/Nozzles/` - nozzle exports
- `CAD STEP Files/Pulleys/` - pulley exports
- `CAD STEP Files/Wire Collection System/` - wire collection subsystem exports
- `CAD STEP Files/Wire Pull Axle Assembly/` - wire-pull axle subsystem exports
- `CAD STEP Files/Wire Tension Housing/` - wire-tension housing subsystem exports

SolidWorks lock or owner files beginning with `~$` are not design-credit entries.
